#  WebShop — Простое веб-приложение на Python

## 📋 Описание проекта

WebShop — это учебный проект, демонстрирующий создание веб-приложения **без использования сторонних фреймворков** (Django, Flask и т.д.). Приложение написано на стандартной библиотеке Python и показывает, как работают HTTP-запросы «под капотом».

Проект реализует интернет-магазин с четырьмя страницами: Главная, Каталог, Категория и Контакты, а также обрабатывает GET и POST запросы, отдаёт HTML-страницы и выводит данные формы в консоль.

## 🛠 Технологии

- **Python 3.14** — стандартная библиотека (`http.server`, `urllib.parse`, `os`)
- **HTML5 + CSS3** — разметка и стилизация страниц
- **Bootstrap 5.3.2** — подключён через CDN для адаптивной вёрстки
- **Git + GitHub** — контроль версий и сдача работы через Pull Request
